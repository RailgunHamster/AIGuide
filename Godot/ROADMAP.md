# AI Guide 需求与优先级

目标：任何外部 Agent（Claude Code、Codex 等）都能 **看见、操作、并可视化地指引** Godot 编辑器里人能操作的一切。
原则：尽量做成纯插件；只有非常通用、插件确实做不到的需求才考虑改引擎，并且改之前先确认。

版本：0.1 为 GDScript 实现；**0.2 起改为 C#**（需要 .NET 版编辑器），功能一致，并在 4.8-beta2 .NET 版上重新做了全流程验证（HTTP 14/14、文件桥、查找/点击/菜单/粘贴/快捷键、演练与回滚、配方、引导覆盖层与气泡按钮、从头开始回滚、热重载）。

### 实测验证过的场景
- 引导"修改 Body 的材质颜色"：场景树选中节点 → 检查器材质行（自动滚动）→ 展开后的子检查器里的 Albedo/Color（穿过两层滚动容器自动滚动）→ 打开取色器，完成条件与自动跳步都正确。
- 菜单栏 → 弹出菜单项 → 打开"项目设置"原生对话框；在对话框里高亮、输入中文、点"关闭"。
- 按钮连续点击 10/10 生效。

### 已知限制与引擎层面的发现
- **悬停依赖系统光标（已用引擎补丁解决）**：Godot 对原生窗口的悬停判断（`Viewport::_update_mouse_over` 里的 `windowmanager_window_over`）取决于操作系统认为光标在哪个窗口上，合成的移动事件不能单独让按钮进入悬停，而按钮要求按下时处于悬停。
  - 引擎补丁：[`patches/ai_guide_synthetic_hover.patch`](patches/README.md)（搜索 `[AI Guide patch]`），已在 4.8-beta2（普通版与 .NET 版）编译验证：10/10 点击生效、全流程回归通过，全程真实光标位置不变。
  - 未打补丁时的兜底：短暂移动真实光标再移回（`move_cursor` 参数可关）。**用户同时在用鼠标时这条路会失败**，实测已复现。
  - 插件会自动判断：先只用合成事件，确认目标进入悬停就直接点；否则才走兜底。ui_act 的报告里 `cursor_moved: true` 表示走了兜底。
- `DisplayServer.warp_mouse()` 的坐标以"最后获得焦点的窗口"为原点，弹窗开关之后这个窗口可能已失效；兜底路径里用"移动后读回位置再校正"处理。
- 键盘事件不能带自定义设备号（输入动作匹配会比较设备号），所以只有鼠标事件能区分"人点的/AI 点的"。
- ~~偶发卡死~~（GDScript 版，已查明并修复）：编辑器扫描文件系统时（窗口重新获得焦点、或整盘扫描），如果发现本插件的 tools.gd 被外部改过，会在更新脚本文档时对它 `reload_from_file`（engine `EditorFileSystem::_update_script_documentation`），所有挂起在 tools.gd 上的工具协程被直接丢弃，请求永远不返回。可稳定复现：外部改 tools.gd 后在 editor_exec 里 `scan()` 再等待。修复：热重载器在重新启用插件后立刻补一次扫描，把编辑器的文件缓存同步掉；回滚只对删掉的文件 `update_file`，不再整盘扫描；超时提示里写明原因。只在开发插件、从外部改它的脚本时出现，普通使用不受影响。
- C# 版的对应情况：重新构建后编辑器重新加载程序集，正在执行的工具请求会被丢弃；HTTP 服务端与文件桥 30 秒兜底返回错误。只在开发插件时出现。
- HTTP 通道：已用官方 MCP Python SDK 实测 14 项（握手/列工具/读写类工具/图片/未知工具/GET 405/外部 Origin 403/localhost Origin 200/错误路径 404/通知 202）。修过一个只在 HTTP 路径出现的 bug：Packed 数组在字典里是值类型，接收缓冲区原先永远是空的。

## P1.5 —— 可靠性：引导不卡住、路径能自动补全
- 显露路径自动规划：目标被隐藏时，自动把"切标签页 / 展开分组 / 展开树节点 / 打开菜单"插入成前置步骤（P0 已能诊断原因，P1 自动生成步骤）。
- 语义 → UI 路径映射：给出"节点 X 的属性 Y"，自动生成"在场景树选中 X → 检查器展开分组 → 定位属性 Y"的完整引导。
- 更多完成条件：属性被修改、资源被保存、指定窗口打开/关闭、快捷键被按下。
- 偏离检测：用户点错时在气泡里提示，并通知 Agent 重新规划（目前 Agent 需轮询 guide_status）。
- locator 跨语言稳定：编辑器语言不同（中文/英文）时节点名和文字会变，改用类名 + 属性路径 + 图标/动作 ID 等与语言无关的身份字段。
- 单窗口模式 / 嵌入式子窗口下的坐标与覆盖层验证。
- stdio 适配器（给只支持 stdio 的 MCP 客户端，几十行脚本转发到 HTTP）。
- 服务端推送（SSE）：引导进度变化主动通知 Agent，不必轮询。

## P2 —— 覆盖自绘区域：真正做到"人能点的 AI 都能点"
自绘区域内部没有子节点，需要逐个写适配器，把内部元素暴露成虚拟节点：
- 3D/2D 视口：gizmo 手柄、选中物体在屏幕上的位置、视口工具栏。
- 脚本/着色器编辑器：按行列定位文本、跳转、选区。
- GraphEdit 类编辑器（可视化着色器、动画树）：节点、端口、连线。
- 动画编辑器：轨道、关键帧、时间轴。
- TileMap / GridMap 绘制区、曲线编辑器、渐变编辑器、颜色选择器。
